Modern Warfare 2 Enhanced {VERSION} (32-bit game): campaign co-op for Call of Duty: Modern Warfare 2 (2009), two players
https://github.com/stxlvn/mw2_enhanced

=== По-русски ===

Это сборка для старой 32-битной версии MW2 из Steam (до сентябрьского обновления 2026, iw4sp.exe
32-бит). Для актуальной 64-битной версии берите обычный архив mw2coop-<версия>.zip, клиент iw4x-sp тоже
работает с этим архивом. На любой другой сборке игры мод сам выключается и ничего не делает.

Установка (у обоих игроков): в папку игры (рядом с iw4sp.exe) положите winmm.dll и папку mw2coop из этого архива.
Ничего из игры не заменяется. Остальное (лобби, вход, сохранения, брандмауэр, разделённый экран) как в обычном
архиве: см. INSTALL.txt в нём и README на GitHub. У обоих игроков должны быть ОДИНАКОВЫЕ файлы мода.
Удаление: удалите winmm.dll и папку mw2coop.

Что есть: сетевой кооператив, разделённый экран на одном ПК (Кампания -> РАЗДЕЛЕНИЕ ЭКРАНА) со всем, что есть в
64-битной версии (лобби с выбором устройства, геймпады, помощь в прицеливании, вибрация, настройки геймпада),
ретрансляция Steam.
Проверено ботами: сетевой кооператив двух копий на одном ПК, пара "хост 64-бит + клиент 32-бит" на тренировке,
разделённый экран на тренировке и в "Скалолазе". Не проверено: игра через интернет между двумя ПК на этой сборке,
кампания целиком, настоящие геймпады.
Проблемы: приложите mw2coop\mw2coop.log обоих игроков.

Клиент iw4x-sp: этот архив работает и с ним. Положите winmm.dll и папку mw2coop рядом с iw4sp.exe и iw4x-sp.exe (iw4sp.exe версии 1.0.159) и запускайте игру через iw4x-sp.exe как
обычно; мод сам узнаёт клиент. iw4x-sp по умолчанию зовёт всех "Unknown Soldier": задайте свой ник командой name <ник> в консоли.
Проверено ботами на клиенте iw4x-sp: сетевой кооператив двух копий на одном ПК (тренировка) и разделённый экран на тренировке.

=== English ===

This is the build for the older 32-bit Modern Warfare 2 on Steam (before the September 2026 update, 32-bit
iw4sp.exe). For the current 64-bit game use the normal archive mw2coop-<version>.zip, the iw4x-sp client works with
this archive too. On any other build of the game the mod switches itself off.

Install (both players): the game folder (next to iw4sp.exe) <- winmm.dll and the mw2coop folder from this archive.
Nothing of the game is replaced. The rest (lobby, joining, saves, firewall, split screen) works as in the normal
archive: see its INSTALL.txt and the README on GitHub. Both players need the SAME mod files.
Uninstall: delete winmm.dll and the mw2coop folder.

What it has: online co-op, the split screen on one PC (Campaign -> SPLIT SCREEN) with everything of the 64-bit build
(lobby with the device choice, gamepads, aim assist, vibration, gamepad options), the Steam relay.
Checked with bots: online co-op of two copies on one PC, a 64-bit host with a 32-bit client on the Trainer, the split
screen on the Trainer and Cliffhanger. Not checked: playing over the internet between two PCs on this build, the whole
campaign, real gamepads.
Problems: attach mw2coop\mw2coop.log from both players.

The iw4x-sp client: this archive works with it too. Put winmm.dll and the mw2coop folder next to iw4sp.exe and iw4x-sp.exe (the 1.0.159 iw4sp.exe) and start the game through
iw4x-sp.exe as usual; the mod recognises the client by itself. iw4x-sp calls everybody "Unknown Soldier" by default: set your own name with name <nick> in the console.
Checked with bots on the iw4x-sp client: online co-op of two copies on one PC (the Trainer) and the split screen on the Trainer.

Not affiliated with or endorsed by Activision or Infinity Ward. mw2coop's own code is MIT licensed (LICENSE.txt).
No game files are included.

Developer console: press the key left of 1 (` or ~) in the game to open it over the top of the picture; "help" lists what it
knows (game commands, dvar values, cmdlist, dvarlist, dvardump, find, condump, Tab completion). The same key closes it.
