mw2coop {VERSION} (32-bit game, experimental): campaign co-op for Call of Duty: Modern Warfare 2 (2009), two players
https://github.com/stxlvn/mw2_coop

=== По-русски ===

Это ЭКСПЕРИМЕНТАЛЬНАЯ сборка для старой 32-битной версии MW2 (до сентябрьского обновления 2026,
iw4sp.exe 32-бит). Для актуальной 64-битной версии берите обычный архив mw2coop-<версия>.zip (без -x86).
На любой другой сборке игры мод сам выключается и ничего не делает.

Проверено: две копии игры на одном ПК играют кооператив-сессию (вход по адресу), скрипты патчатся
так же, как в 64-битной версии, пара "хост 64-бит + клиент 32-бит" проверена на тренировке.
Не проверено и не перенесено: игра через интернет между двумя ПК на 32-битной сборке, приглашения
Steam и ретрансляция Steam, помощник скриншотов; кампания целиком на 32-битной версии не пройдена.

Установка (у обоих игроков): папка игры (рядом с iw4sp.exe) <- winmm.dll и папка mw2coop из этого
архива. Ничего из игры не заменяется. Остальное (лобби, вход, сохранения, брандмауэр) как в
обычном архиве: см. INSTALL.txt в нём и README на GitHub. У обоих игроков должны быть ОДИНАКОВЫЕ
файлы мода. Удаление: удалите winmm.dll и папку mw2coop.
Проблемы: приложите mw2coop\mw2coop.log обоих игроков.

=== English ===

This is an EXPERIMENTAL build for the older 32-bit Modern Warfare 2 (before the September 2026 update,
32-bit iw4sp.exe). For the current 64-bit game use the normal archive mw2coop-<version>.zip (without -x86).
On any other build of the game the mod switches itself off.

Checked: two copies of the game on one PC play a co-op session (joining by address), the scripts are
patched as in the 64-bit build, and a 64-bit host with a 32-bit client was checked on the range.
Not checked or not ported: playing over the internet between two PCs on the 32-bit build, Steam
invites and the Steam relay, the screenshot helper; the whole campaign has not been played on the
32-bit game.

Install (both players): the game folder (next to iw4sp.exe) <- winmm.dll and the mw2coop folder from
this archive. Nothing of the game is replaced. The rest (lobby, joining, saves, firewall) works as in
the normal archive: see its INSTALL.txt and the README on GitHub. Both players need the SAME mod
files. Uninstall: delete winmm.dll and the mw2coop folder. Problems: attach mw2coop\mw2coop.log from
both players.
