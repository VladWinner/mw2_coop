mw2coop {VERSION}: campaign co-op for Call of Duty: Modern Warfare 2 (2009), two players
https://github.com/stxlvn/mw2_coop

=== По-русски ===

Что это: кооператив на двоих для кампании MW2 (2009) в актуальной 64-битной Steam-версии.
Альфа: не вся кампания доработана для двоих (список в README.md на GitHub).

Нужно:
- Windows 10/11, MW2 (2009) в Steam (appid 10180), 64-битная сборка (обновление сентября
  2026). На другой сборке мод сам выключается и ничего не делает.
- Игра у каждого из двух игроков, и ОДИНАКОВЫЕ файлы мода у обоих (иначе рассинхрон).
- Хосту: открытый UDP-порт 28960 (проброс на роутере) или общая локальная сеть / VPN
  (Radmin VPN, ZeroTier и т. п.).

Установка (у обоих игроков):
1. Steam -> Библиотека -> Modern Warfare 2 -> Управление -> Просмотреть локальные файлы.
   Откроется папка с iw4sp.exe.
2. Скопируйте туда всё из этого архива: winmm.dll, папку mw2coop и файлы .bat.
   (Ничего из игры не заменяется: добавляются новые файлы.)

Игра (всё в меню игры):
1. Хост: Кампания -> СЕТЕВАЯ ИГРА ВДВОЕМ. Откроется лобби с миссией, на которой вы
   остановились (или первой). "Выбор операции" меняет миссию, "Доступ" - кто может войти:
   свободный / только друзья Steam / по паролю.
2. Второй игрок:
   - друг по Steam: хост жмёт "Пригласить друга", друг принимает приглашение в Steam;
   - по сети (одна локальная сеть или Radmin VPN): Кампания -> ПРИСОЕДИНИТЬСЯ К ИГРЕ,
     выбрать игру в списке (или "Ввести адрес вручную..." и ввести IP хоста).
3. Оба жмут "Готов", хост жмёт "Старт".
Прогресс хранится у хоста (mw2coop\progress.txt): в следующий раз лобби откроется там же.

Если второй игрок по сети не может подключиться: хост запускает mw2coop-firewall.bat (один
раз; Windows спросит права администратора, только если правила для игры нет). Через интернет
без общей сети хосту нужен проброс UDP-порта 28960 на роутере, либо Radmin VPN.
Порт меняется в mw2coop\settings.ini (у обоих одинаковый).

Старый способ без меню (на всякий случай): mw2coop-host.bat / mw2coop-continue.bat у хоста,
mw2coop-join.bat у второго игрока.

Удаление: удалите из папки игры winmm.dll, папку mw2coop и файлы mw2coop-*.bat.
(Правило брандмауэра, если его добавлял mw2coop-firewall.bat: "Call of Duty MW2 co-op (mw2coop)".)
Проблемы: приложите mw2coop\mw2coop.log обоих игроков.

=== English ===

Two-player co-op for the MW2 (2009) campaign on the current 64-bit Steam build. Alpha: not
every mission is reworked for two yet (see README.md on GitHub).

Needs: Windows 10/11; MW2 (2009) on Steam (appid 10180), the 64-bit build (September 2026
update; on any other build the mod switches itself off); the game and the SAME mod files on
both PCs; for the host, UDP port 28960 reachable (port forward) or a shared LAN/VPN.

Install (both players): Steam -> Library -> Modern Warfare 2 -> Manage -> Browse local files
(the folder with iw4sp.exe). Copy everything from this archive there: winmm.dll, the mw2coop
folder and the .bat files. Nothing of the game is replaced.

Play (in the game's menus): the host picks Campaign -> TWO PLAYERS ONLINE; the lobby opens
on the mission where you stopped (Change Op picks another; Access sets who may join: open,
Steam friends only, or a password). The partner joins through a Steam invite (Invite Friend),
or on a shared network (LAN, Radmin VPN) through Campaign -> JOIN A GAME (pick the game from
the list, or enter the host's address). Both press Ready, the host presses Start. Progress is
kept by the host (mw2coop\progress.txt).

If the partner cannot join over the network, the host runs mw2coop-firewall.bat once (it asks
for administrator rights only if the game has no firewall rule). Over the internet without a
shared network the host needs UDP port 28960 forwarded, or Radmin VPN. The port can be changed
in mw2coop\settings.ini (the same on both PCs). The old .bat launchers still work.

Uninstall: delete winmm.dll, the mw2coop folder and the mw2coop-*.bat files from the game
folder. Problems: attach mw2coop\mw2coop.log from both players.
