# Hand-written descriptions for tools/gen_settings_reference.py: "section.key text". They win over every other source.
# Say only what the code shows; a key whose meaning is not clear stays without a line here (the generator then says so).
console.favorites_defaults_initialized Written by the console (1) once it has added its default pinned commands (mapname, viewposNow), so they do not come back after you unpin them. Not for editing.
console.zoom_pct Console scale, 50-300 (percent): the whole interface (text, controls, spacing); Ctrl++, Ctrl+-, Ctrl+mouse wheel, Ctrl+0 resets to 100, or the output context menu.
console.opacity_pct Console window opacity, 30-100 (percent); the Transparency slider in the output context menu.
console.word_wrap 1 (the default): output lines wrap at the window width; 0: they keep their full length and the output scrolls sideways (Shift+mouse wheel, horizontal wheel, the bar under the output). Output context menu.
console.colorize 1 (the default): the ^ color codes in the output are drawn; 0: everything uses the default color. Output context menu.
console.line_numbers 1: a line-number column left of the output (a wrapped line keeps one number); 0 (the default): none. Output context menu.
console.show_mod_messages 1 (the default): the mod's own log lines (mw2coop.log) are also printed in the console, gray; 0: not. Output context menu.
console.window_custom 1: the console window opens at the position and size saved in window_left_pct, window_top_pct, window_width_pct and window_height_pct (the console writes them when you move or resize it). Not for editing.
console.window_left_pct Saved left edge of the console window, 0-10000 (hundredths of a percent of the screen); -1 = not set. Used only with window_custom=1; written by the console.
console.window_top_pct Saved top edge of the console window, 0-10000 (hundredths of a percent of the screen); -1 = not set. Used only with window_custom=1; written by the console.
console.window_width_pct Saved width of the console window, 1-10000 (hundredths of a percent of the screen); -1 = not set. Used only with window_custom=1; written by the console.
console.window_height_pct Saved height of the console window, 1-10000 (hundredths of a percent of the screen); -1 = not set. Used only with window_custom=1; written by the console.
display.fsr3_sharpness FSR 3's sharpening, 0-100 (0 = off); a value outside the range becomes 60. See the [display] comments in settings.ini.
native.padmovedead Gamepad left stick dead zone in percent (default 18), for the split screen's pads.
native.paddead Gamepad right (look) stick dead zone in percent (default 22), for the split screen's pads.
native.padcurve Gamepad stick response curve in percent (default 160 = the curve exponent 1.6), for the split screen's pads.
native.padtrigger Gamepad trigger threshold in percent of full travel (default 30), for the split screen's pads.
native.p1pad The device of player 2 (the bottom half): an XInput pad 0-3, or -1 for the keyboard and mouse. The lobby and the menu launch set it; a value in the file is for tests.
native.p1name Name tag of player 1 in the split screen (empty = Alpha).
native.p2name Name tag of player 2 in the split screen (empty = Bravo).
native.p1cmd 1: a start value is written into the view angle accumulators of context 1 (player 2), see p1yawdeg. QA.
native.p1yawdeg With p1cmd=1: the yaw in degrees written into context 1's view angle accumulator (default 60). QA.
native.nopredict 1: player 2's view shows the server's player state as it is, without the client's own prediction (the dvar cg_nopredict; testing).
native.sites Bit mask of which of the split screen's hook sites to install (default 0x7fffffff = all). Testing; a missing bit leaves that part of the game unpatched.
native.swapsites 1: notes the call sites of the context swap in the log (testing).
native.timelogskip With timelog=1: the number of draws to skip before the 6000 logged ones. Testing.
native.msecsplit 1 (default): each player in split screen keeps his own "time the usercmds were last made", so player 2's frame_msec is not 0 and his mouse turns his view (Big Brother, 2026-11-18). 0: the time is shared again (player 2's mouse look does nothing). Off by itself on a game build where the address was not found.
native.lasersplit 1 (default): each player in split screen keeps his own list of the laser sights to draw, so player 2's half draws every laser beam once (2026-11-21). 0: one list, each beam drawn twice in player 2's half. Off by itself on a game build where a part of the list was not found.
native.vehupd1 1 (default): in split screen only player 1's view runs the vehicles' client update (their time, tread scroll and engine sound), so the engine sounds start once (2026-11-21). 0: both views run it, as the game does.
native.shockslot 1 (default): player 2's shell shock blend and saved screen use the game's second timer slot, so the two players' dazed views do not share one (Endgame's wake-up, 2026-11-18). 0: one slot, as the game has it.
native.shocksect 1 (default): the shell shock's saved screen copies only the rectangle of the view being drawn, not the whole back buffer (64-bit: a patch of the game's copy; 32-bit: the copy is made by the mod). 0: the whole screen, which smears player 2's half.
native.qa_mouse1dx QA: a steady mouse movement fed to player 2 in split screen, in counts per frame (no real cursor is moved): checks that his view turns. 0 (default): off.
native.cmdlog1 QA: logs player 2's usercmd angles, the key catchers, frame_msec and his mouse reads, 4 times a second (64-bit; Big Brother's gunner). 0 (default): off.
native.padfreeze While a player's controls are frozen (a script's FreezeControls, a linked scene) his pad's stick moves nothing, as the keyboard's keys move nothing then (default 1): the Spec Ops snowmobile races hold the pad player until GO. 0: the pad's move goes through (a vehicle then drives off while frozen).
native.shadercache The same Direct3D 9 shader bytecode gives the same shader object back instead of a new one (default 1): the game makes one shader for every copy of it in a zone, and the next level makes most of the last one's again, each a compile in the driver; the log has the numbers before every level (d3dcap: shader cache before ...). 0: the game's own way.
voice.mic A part of the microphone's name as Windows lists it (default empty: Windows' default recording device).
voice.talk_key The key that, held, talks to the partner in network co-op (default CAPSLOCK); the mod binds it to +mw2coop_talk once, when the player's config binds that key to nothing else. Empty: no key is bound.
voice.volume_pct The partner's voice, 0 to 200 (default 100).
native.pingmouse The markers' wheel holds the view while it is open: the mouse read of CL_MouseMove is hooked from the start, in network co-op too (default 1). 0: not hooked; the wheel then turns with the view and picks nothing by the mouse.
